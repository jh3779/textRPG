# 00. 프로젝트 브리프

> 인터뷰 영역 1~3 (문제·목표 / 사용자·맥락 / 가치·성공 지표) 정리
> 작성일: 2026-09-04 · 상태: draft (2026-08-18 웹 버전 기획을 대체 — Unity 방향으로 전면 재설계)

## 한 문장 정의
textRPG Unity판은 C++ 콘솔 텍스트 RPG의 던전 세계관과 규칙을 그대로 가져와, 초상화·텔리지 UI 기반의 시각적 TRPG로 "승격"한 Unity 데스크톱 게임이다.

## 문제 · 목표 (왜)
- **푸는 문제:** 콘솔 텍스트 RPG는 문법 학습용으로는 완성됐지만, 텍스트만으로는 보여주기 어려운 캐릭터성·분위기·직업 다양성을 표현할 수 없다.
- **현행 대안:** 지난 세션에서 "웹 브라우저 플레이 버전"으로 기획을 시작했으나(구 `docs/00~07`), 이번에 방향을 Unity 기반 시각적 TRPG로 전면 교체했다 — 웹 버전 기획은 폐기.
- **성공 시 변화:** 같은 던전(입구→갈림길→무기고→통로→보스방)과 전투 규칙을 유지하면서, 직업 선택·캐릭터 초상화·시각화된 전투 UI로 실제 게임처럼 몰입감 있게 플레이 가능해진다.
- **10-star 비전 (예산·시간 무제한이라면):** 사용자가 자신만의 세계관·스토리 파일을 업로드하면 AI가 그 세계관에 맞춰 지역·몬스터·직업을 생성해 새 게임을 시작할 수 있고, 여러 명이 함께 접속해 파티 플레이(멀티플레이)를 할 수 있는 범용 TRPG 플랫폼. **이번 MVP는 이 방향으로 가는 첫걸음이지만, 커스텀 세계관 업로드와 멀티플레이는 이번 범위에서 명시적으로 제외한다** (01_requirements.md Won't 참조) — 방향은 같은 길 위에 있지만 지금 만드는 건 훨씬 작다.

## 대상 사용자 · 맥락
| 항목 | 내용 |
|------|------|
| 1차 사용자 | 우지훈 본인 (Unity·게임 UI 학습 겸 포트폴리오 검증) |
| 2차 사용자/수신자 | 포트폴리오를 보는 제3자 |
| 사용 맥락 | 데스크톱 스탠드얼론 실행 파일(.exe), 키보드+마우스, 한 세션에 10~20분 내외 플레이 |

## 핵심 가치 · 성공 지표
- **핵심 가치:** "텍스트로만 상상하던 던전을, 초상화와 함께 실제로 본다."
- **성공 지표:** 직업을 골라 던전 입구부터 보스방까지, 콘솔 버전과 동일한 규칙으로 완주 가능한가. 텍스트 대신 시각 정보(초상화·HP바·아이콘)로도 상황이 즉시 파악되는가.
- **반드시 지킬 품질:** 전투 수치·확률·스토리 분기는 콘솔 버전(C++ Game/BattleSystem)과 동일하게 유지한다 — Unity로 옮기며 게임 밸런스를 바꾸지 않는다(단, 직업별 시작 스탯 차이는 신규 추가).

## 비전 대비 MVP 경계 (요약)
MVP는 싱글플레이 + 기존 던전 세계관 1개(재사용) + 직업 2~3개(시작 스탯만 다름) + 시각화된 탐색·전투 화면까지. 커스텀 세계관 파일 업로드, AI 기반 세계관 생성, 멀티플레이는 전부 Won't(10-star 비전으로 기록만). 자세한 경계는 [01_requirements.md](01_requirements.md) 참조.

# 00. 프로젝트 브리프

> 인터뷰 영역 1~3 (문제·목표 / 사용자·맥락 / 가치·성공 지표) 정리
> 작성일: 2026-08-18 · 상태: draft

## 한 문장 정의
textRPG 웹 버전은 우지훈이 만든 C++ 콘솔 텍스트 RPG(`textRPG`)를, 별도 설치 없이 브라우저에서 그대로 즐길 수 있게 하는 웹 플레이어다.

## 문제 · 목표 (왜)
- **푸는 문제:** 현재 textRPG는 C++로 빌드해야만 실행할 수 있어, 포트폴리오로 보여주거나 다른 사람이 바로 플레이해보기 어렵다.
- **현행 대안:** 저장소를 클론해 CMake/g++로 직접 빌드해야 함 — 진입장벽이 높음.
- **성공 시 변화:** 링크 하나로 브라우저에서 즉시 플레이 가능. 콘솔 버전과 동일한 게임 경험(맵 이동, 전투, 인벤토리, 퀘스트, 세이브/로드)을 제공.

## 대상 사용자 · 맥락
| 항목 | 내용 |
|------|------|
| 1차 사용자 | 우지훈 본인 (학습·포트폴리오 검증) |
| 2차 사용자/수신자 | 포트폴리오/GitHub를 보는 제3자 (채용 담당자, 스터디원 등) |
| 사용 맥락 | 데스크톱 브라우저에서 짧게(5~15분) 플레이. 모바일에서도 깨지지 않아야 하지만 최적화 우선순위는 낮음. 로그인/계정 없이 그 자리에서 바로 플레이. |

## 핵심 가치 · 성공 지표
- **핵심 가치:** "빌드 없이, 링크만으로 즐기는 textRPG."
- **성공 지표:** 별도 안내 없이 처음 접속한 사람이 콘솔 버전과 동일하게 처음~던전 클리어(또는 게임 오버)까지 완주할 수 있는가.
- **반드시 지킬 품질:** 기존 C++ 게임 로직과 동일한 규칙(밸런스·확률·텍스트)을 그대로 유지 — 웹 버전이라고 게임플레이가 달라지면 안 됨.

## 비전 대비 MVP 경계 (요약)
MVP는 C++ 콘솔 버전의 전체 기능(맵 5곳 이동, 턴제 전투, 인벤토리, 퀘스트 1개, 브라우저 저장/불러오기)을 웹으로 그대로 옮기는 것까지. AI 던전마스터(`ai_service`) 연동은 이번 범위에서 **제외**하고 다음 단계로 미룬다. 자세한 경계는 [01_requirements.md](01_requirements.md) Could/Won't 참조.

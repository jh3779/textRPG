### PixelLab 조사 (2026-09-04, OQ-105 후보 — 아직 확정 아님)
사용자 요청으로 [pixellab.ai](https://www.pixellab.ai) 조사. 게임 에셋 전용 AI 생성 서비스로, 이번 10-star 비전의 "재사용 가능 인프라"(외부 API 호출)에 기술적으로 잘 맞는다.

| 항목 | 내용 |
|------|------|
| 생성 종류 | 픽셀아트 전문 — 캐릭터(스켈레톤 기반 포즈 컨트롤), 4/8방향·아이소메트릭 회전 뷰, 걷기/공격 등 애니메이션, 배경·타일셋, UI 요소(버튼·체력바) |
| 스타일 일관성 | 참조 이미지 기반으로 같은 캐릭터의 여러 포즈·장비 변형을 스타일 일치시켜 생성(인페인팅) — 10-star 비전 표의 "스타일 일관성" 요구와 잘 맞음 |

| 비용 | 크레딧 기반 종량제. 예: 64×64 이미지 $0.00793, 128×128 애니메이션 $0.0145 — 개인 프로젝트 규모에 부담 없는 수준 |

**⚠️ 스타일 충돌 — 확정 전 반드시 짚어야 함:** PixelLab은 **픽셀아트** 전문 서비스다. 반면 `07_visual_style.md`에 이미 확정된 방향은 "전신 일러스트풍 실루엣" + 양피지·나무 질감의 사실적/회화적 톤(다크 판타지 태블탑)이다. 둘은 서로 다른 그림체라 — PixelLab을 쓰려면 비주얼 스타일 자체를 픽셀아트 방향으로 다시 틀어야 하고(레트로 텍스트 RPG 원작 정체성과는 오히려 잘 맞을 수 있음), 지금 스타일을 유지하려면 PixelLab 대신 일반 일러스트 생성 API(DALL-E·Stability 등)를 써야 한다. **이 결정은 아직 안 함** — OQ-105 확정 시점(착수 전)에 비주얼 스타일과 함께 다시 논의.

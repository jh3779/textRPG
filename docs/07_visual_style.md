# 07. 비주얼 스타일 — 레트로 · 터미널

> `style-picker` 인터뷰 결과 · 상태: confirmed (2026-08-18)
> 스타일은 이 하나로 통일한다 — 다른 스타일과 섞지 않는다.

## 컨셉
옛 컴퓨터 터미널에서 텍스트 어드벤처를 하던 느낌. textRPG가 원래 C++ 콘솔 게임이라는 정체성을 그대로 웹으로 옮긴다. 화려한 장식보다 "터미널 그 자체"의 질감(단색 배경, 모노스페이스, 프롬프트, 깜빡이는 커서)으로 몰입감을 만든다.

## 색상
| 용도 | 값 | 비고 |
|------|-----|------|
| 배경 | `#0d0d0d` | 거의 검정, 순수 검정(#000)보다 눈부심 적음 |
| 기본 텍스트 / 포인트 컬러 | `#39ff14` (네온 그린) | 서술 텍스트, 선택지, 테두리 |
| 경고/위험 (HP 낮음, 패배) | `#ff3b3b` | 최소한으로만 사용 — 상태 신호 용도 |
| 보조 정보 (라운드 수, 골드 등 메타 정보) | `#7a7a7a` (딤 그레이) | 본문과 위계 구분용 |
| 강조 배경 (선택된 항목) | `#39ff14` 10% 불투명도 오버레이 | 순수 배경색 대비 유지 |

원칙: 포인트 컬러는 네온 그린 하나. 경고색(빨강)은 HP 위험/게임 오버 같은 상태 신호에만 예외적으로 쓰고, 장식 목적으로 색을 늘리지 않는다.

## 타이포그래피
- 전체 모노스페이스: `"JetBrains Mono", "Fira Code", ui-monospace, "Courier New", monospace`
- 본문(서술 텍스트): 16px 기준, 줄간격 1.6 (콘솔 출력처럼 읽히도록 넉넉하게)
- 선택지: `> 1. 던전에 들어간다` 형태의 프롬프트 접두사(`>`) 고정
- 강조: 볼드 대신 **밝기(색상 진하기)** 로 위계 표현 (터미널에는 굵기 변화가 어색함)

## 레이아웃 · 모션
- 상태 바(HP/공격력/골드 등)는 화면 상단에 고정된 한 줄 — 콘솔의 `[라운드 N] ...` 출력 형식을 그대로 재현
- 서술/선택지 영역은 위에서 아래로 누적되는 로그처럼 표시(스크롤 가능) — 콘솔의 연속 출력 느낌 재현(01_requirements Could 항목과 연결)
- 텍스트는 타이핑 효과(한 글자씩 출력)로 나타나되, **클릭/키 입력으로 즉시 전체 표시(skip) 가능** — REQ-NF-005(접근성) 충족 필수, 애니메이션이 읽기를 방해하면 안 됨
- 테두리/구분선은 장식 없는 1px 네온 그린 선, 또는 `─ │ ┌ ┐ └ ┘` 문자 기반 ASCII 박스 중 하나로 통일(design-generation 단계에서 하나 확정)
- 커서: 입력 대기 지점에 깜빡이는 `█` 블록 커서로 "다음 입력을 기다리는 터미널" 느낌 강조

## 하지 않는 것
- 그라디언트, 글래스모피즘 블러, 둥근 카드형 UI 금지 — 터미널 정체성과 충돌
- 색상을 3개 이상 동시에 화면에 강조색으로 쓰지 않는다(네온 그린 + 예외적 경고색 빨강까지만)
- 실사 이미지/일러스트 사용 안 함 — 텍스트와 ASCII만으로 구성

## 접근성 메모
- 네온 그린(#39ff14) on 배경(#0d0d0d) 대비비 확인 필요(WCAG AA, REQ-NF-005) — 실제 구현 시 대비 도구로 검증
- 타이핑 애니메이션은 `prefers-reduced-motion` 설정 시 자동으로 즉시 표시로 전환

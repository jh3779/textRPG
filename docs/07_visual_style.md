# 07. 비주얼 스타일 — 다크 판타지 태블탑(보드게임) UI

> `style-picker` 인터뷰 결과 · 상태: confirmed (2026-09-04 확정, 2026-09-04 보드게임 방향으로 레이아웃 재작업)
> 색·타이포는 기존 "Gilded Dungeon"(다크 판타지) 그대로 유지하고, **레이아웃과 재질을 실제 테이블탑 TRPG를 펼쳐놓은 형태로 재작업**한다. 스타일은 이 하나로 통일 — 다른 스타일과 섞지 않는다.

## 컨셉
어두운 나무 테이블 위에 양피지 카드·던전 보드판·주사위를 펼쳐놓고 플레이하는 느낌. 화면 자체가 "앱"이 아니라 "테이블 위에 차려진 게임"처럼 보여야 한다 — 평평한 카드/표 대신 물리적 재질(나무·양피지·금속 프레임)과 테이블탑 요소(보드판 타일, 카드, 주사위, 캐릭터 시트)를 UI 언어로 쓴다.

## 색상 (기존 Gilded Dungeon 유지)
| 용도 | 값 | 비고 |
|------|-----|------|
| 배경(테이블) | `#0f0d1a` 바탕 + 나무결 텍스처(아래 "재질" 참조) | 순수 검정보다 은은한 깊이감 + 나무 질감 |
| 카드/시트 배경(양피지) | `#e8dcc0` 크림톤 (다크 테이블 위에 올린 밝은 카드) | 텍스트 서술·선택지·아이템은 이 위에 놓임 |
| 패널 배경(양피지 없는 UI 틀) | `#1c1826` | 상태바 등 순수 UI 요소 |
| 포인트 컬러 | `#d4af37` (금색) | 제목, 선택된 카드 테두리, 확정 버튼, 보드 위 현재 위치 토큰 |
| HP 바 | `#b23a3a` (짙은 적색) | 금속 프레임 안에 채움 |
| 경험치/보조 정보 | `#8f88a8` (은은한 보라 그레이) | 본문과 위계 구분 |
| 위험/경고 (HP 낮음, 패배) | `#ff5a5a` | 최소한으로만 사용 |

원칙은 기존과 동일: 포인트 컬러는 금색 하나, HP 적색만 기능적 예외.

## 재질 (신규 — 보드게임 방향의 핵심)
- **나무 테이블**: 전체 배경에 은은한 나무결(가로 줄무늬 그라디언트, 저채도 갈색~검정) — 화면 전체가 "테이블 표면"
- **양피지 카드**: 선택지·아이템·퀘스트는 크림톤 양피지 질감 카드 위에 표시. 모서리를 살짝 비대칭으로 두거나 얇은 그림자로 "테이블 위에 놓인 종이" 느낌
- **금속 프레임**: 초상화·HP바는 기존과 동일하게 금색 금속 테두리 — 카드(종이)와 대비되는 재질로 위계 구분
- **주사위 모티프**: 전투/확률이 개입하는 지점(공격 판정, 도망 시도)에 주사위 아이콘을 시각적 장식으로 사용(실제 랜덤 연출까진 아니어도 "판정"이라는 의미를 시각적으로 암시)

## 타이포그래피 (기존 유지)
- 제목/화면명: 세리프(Cinzel) — 고전 판타지 인장 느낌, 카드 상단 라벨에도 동일 적용
- 본문(서술 텍스트): Pretendard, 16px 기준 — 양피지 카드 위에서도 이 폰트 유지(손글씨체로 바꾸지 않음 — 가독성 우선)
- 수치(HP·공격력 등): Roboto Mono

## 레이아웃 · 모션 (보드게임 형식으로 재작업)
- **탐색 화면 = 보드판.** 5개 지역을 개별 카드/텍스트로만 보여주지 않고, 지역을 연결하는 작은 보드판/타일 맵을 항상 함께 보여준다. 현재 위치는 금색 토큰(말)으로 표시 — 콘솔 버전의 선형 구조(5개 지역, 되돌아갈 수 없음)는 그대로 유지하되 "지금 어디 있고 다음에 어디로 갈 수 있는지"를 보드 위에서 한눈에 보게 한다.
- **선택지 · 아이템 = 카드.** 메뉴 버튼 목록 대신 타로/플레잉카드 형태(세로로 긴 비율, 상단 라벨 + 중앙 아이콘/일러스트 + 하단 설명)의 카드를 가로로 펼쳐 보여준다. 선택 시 카드가 살짝 들리는(hover lift) 느낌.
- **직업 선택 = 캐릭터 시트.** 아이콘 카드가 아니라 실제 TRPG 캐릭터 시트처럼 양피지 위에 전신 일러스트풍 실루엣 + 스탯 칸(HP/ATK/DEF를 칸으로 구분) + 이름을 배치한다.
- 초상화는 여전히 항상 금속 액자형 프레임 안(전투 화면 등 "인물 강조"가 필요한 곳). 보드 위 토큰은 프레임 없는 단순 원형 마커로 구분(용도가 다름 — 위치 표시 vs 인물 강조).
- HP/MP 바는 기존과 동일(금속 프레임 + 채우는 바).
- **직업 선택 캐릭터는 상반신·얼굴 중심으로 크롭한다(2026-09-04 확정).** 전신 실루엣이 아니라, 하체 비중을 줄이고 얼굴이 잘 보이는 흉상(bust) 구도를 쓴다 — 직업 선택은 "누구를 고르는가"가 핵심이라 얼굴 인식이 우선이라는 사용자 판단.
- **탐색·전투 화면은 전체화면 배경(Fullbleed)으로 구성한다(2026-09-04 재설계, 기존 "배경 씬/보드+카드" 조합을 대체).** 작은 배경 패널이 아니라 화면 전체를 그 상황의 배경 일러스트로 채우고, 그 위에 반투명 레이어로 상태 정보·선택지를 얹는다:
  - 탐색: 배경 전체 + 상단 상태 한 줄 + (선택) 보드 타일 맵 + 하단 텍스트바(위치 설명) + 가벼운 outline 버튼(선택지). 기존의 무거운 양피지 선택지 카드 대신 반투명 배경의 얇은 버튼을 쓴다.
  - 전투: 배경 전체(그 전투가 벌어지는 지역의 씬 재사용) 위에 플레이어와 몬스터를 카드 프레임 없이 직접 세워 진짜 "그 자리에서 맞붙는" 대립 구도를 만든다. 인물 이미지 가장자리는 부드럽게 페이드시켜(마스킹) 배경과 자연스럽게 섞는다 — 원본이 진짜 투명 배경이 아니기 때문에 쓰는 처리이며, 나중에 배경 제거된 소스로 교체하면 마스킹 없이도 자연스러워진다. 하단에 텍스트바(전투 로그)와 가벼운 행동 버튼(공격/도망)을 얹는다.
  - 타이틀·직업선택·인벤토리·퀘스트·결과 화면은 기존 나무 테이블+양피지 카드 구성을 유지한다 — 이 재구성은 탐색·전투 두 화면에만 적용.
- 화면 전환은 짧은 페이드 유지. 카드가 새로 놓일 때는 살짝 미끄러져 들어오는(slide-in) 연출을 Could로 남긴다(01_requirements Could와 동일한 우선순위).
- **선택 표시 = 볼펜 잉크 자국(2026-09-04 추가).** 선택지 카드·캐릭터 시트가 선택됐을 때, 금색 아웃라인만으로 표시하지 않고 손으로 볼펜을 동그라미 치듯 그리는 애니메이션(SVG 선 그리기) + 옅은 잉크 번짐(fill 페이드인)을 함께 쓴다 — "내가 직접 표시했다"는 손맛을 준다. 색은 시스템 금색과 구분되는 진남색 잉크색(#2b3f7a)을 써서 "플레이어가 남긴 표식"과 "UI 자체의 강조색"을 구분한다.

## 하지 않는 것
- 밝은 파스텔톤, 네온 컬러 사용 안 함(기존 원칙 유지)
- 초상화 프레임 없이 이미지를 화면에 그냥 띄우지 않는다
- 색상을 3개 이상 동시에 강조색으로 쓰지 않는다(금색 + 기능적 적색까지만) — 재질(나무·양피지)은 색상이 아니라 질감이므로 이 규칙과 별개
- 보드판을 실제 이동 가능한 자유 탐험처럼 보이게 하지 않는다 — 콘솔 버전의 선형 5단계 구조를 시각적으로 왜곡하지 않는다(과장 금지)

## 접근성 메모
- 양피지(크림) 위 텍스트, 나무 배경 위 UI 요소 모두 WCAG AA 대비 확인 필요 — 특히 크림 카드 위 저채도 보조 텍스트는 실제 구현 시 대비 도구로 재검증
- HP 위험 상태를 색(적색)에만 의존하지 않고 숫자와 함께 표시(색맹 고려) — 기존 원칙 유지
- 카드 hover/선택 상태는 색 변화뿐 아니라 테두리 두께·살짝 들리는 모션으로 이중 표현

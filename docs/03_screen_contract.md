# 03. 화면 계약 (Screen Contract)

> 인터뷰 영역 5 정리 — 화면별 "무엇을 반드시 보이고, 무엇을 할 수 있는가" · 상태: draft

## SCR-001 · 타이틀 / 메인 메뉴
- **목적:** 새 게임 시작 또는 기존 진행 이어하기의 진입점
- **진입:** 웹 접속 직후, 또는 게임 오버/승리/저장 후 복귀
- **가시 의무:**
  - 게임 제목
  - "새 게임", "이어하기" 버튼 (이어하기는 세이브 없으면 비활성)
- **행동:**
  - 새 게임 → FLOW-001
  - 이어하기 → FLOW-002
- **상태별 표현:**
  | 상태 | 표현 |
  |------|------|
  | 세이브 없음 | "이어하기" 비활성 + "저장된 게임이 없습니다" 툴팁 |
  | loading(서버 기동 확인) | 버튼 영역에 스피너, 나머지는 그대로 |
  | error(서버 연결 실패) | 에러 배너 + 재시도 버튼, 버튼들은 비활성 |
- **금지:** AI 던전마스터 토글 등 MVP 밖 기능 노출 금지 (REQ-F 목록에 없는 것 발명 금지)
- **근거:** REQ-F-001·006 · FLOW-001·002

## SCR-002 · 탐험 화면
- **목적:** 현재 위치를 확인하고 다음 행동(이동/상태 확인/저장)을 선택
- **진입:** FLOW-001/002/003/004에서 전환
- **가시 의무:**
  - 상단 상태 바: 라운드, 플레이어 이름, HP/최대HP, 공격력, 골드
  - 현재 지역 이름 + 설명 텍스트
  - 해당 지역의 선택지 목록(콘솔 버전과 동일한 문구·순서)
- **행동:**
  - 지역별 선택지 클릭 → 이동/전투 진입/아이템 획득/상태 확인/저장하고 종료
  - 인벤토리 보기 → SCR-004 오버레이
  - 퀘스트 보기 → SCR-005 오버레이
- **상태별 표현:**
  | 상태 | 표현 |
  |------|------|
  | 무기고, 이미 루팅함 | "이미 챙길 만한 장비는 모두 가져갔습니다" 안내 후 통로로 자동 이동 |
  | 어두운 통로, 고블린 이미 처치 | 전투 선택지 대신 "보스의 방으로 간다" 선택지만 표시 |
  | loading(선택 처리 중) | 선택지 버튼 비활성 + 짧은 스피너 |
- **금지:** 전투 로직을 이 화면에서 직접 계산하지 않는다(서버 API 응답 결과만 반영)
- **근거:** REQ-F-001·003·004·006 · FLOW-001·003·004

## SCR-003 · 전투 화면
- **목적:** 턴제 전투 진행 — 공격/도망 선택과 결과 확인
- **진입:** SCR-002에서 전투가 있는 지역 진입 시 (FLOW-003)
- **가시 의무:**
  - 라운드 번호
  - 플레이어 HP/최대HP, 적 이름·HP
  - 직전 턴의 공격/반격 로그(콘솔의 "OO의 공격!" 문구와 동일 톤)
  - "공격한다" / "도망친다" 선택지
- **행동:**
  - 공격 → 결과에 따라 다음 라운드 표시 또는 승리/패배 전환
  - 도망 → 55% 확률로 SCR-002 복귀, 실패 시 적 반격 후 전투 계속
- **상태별 표현:**
  | 상태 | 표현 |
  |------|------|
  | 전투 진행 중 | 위 가시 의무 그대로 |
  | 승리 | "승리했습니다!" + 획득 경험치/골드 → SCR-002 또는 SCR-007로 전환 |
  | 패배 | "전투에서 쓰러졌습니다" → SCR-006으로 전환 |
  | 도망 성공/실패 | 각각의 안내 문구 표시 |
- **금지:** 전투 중 저장하고 종료 선택지 노출 금지(콘솔 버전과 동일한 제약)
- **근거:** REQ-F-002·005 · FLOW-003

## SCR-004 · 인벤토리 패널
- **목적:** 보유 아이템 확인
- **진입:** SCR-002에서 "상태를 확인한다" 또는 인벤토리 보기 행동
- **가시 의무:**
  - 아이템별 이름, 종류(무기/방어구/포션/소비), 효과 값, 설명
  - 현재 개수/최대 용량(5)
- **행동:**
  - 닫기 → SCR-002로 복귀(스택 추가 없음)
- **상태별 표현:**
  | 상태 | 표현 |
  |------|------|
  | empty | "보유한 아이템이 없습니다" |
  | 가득 참 | 용량 표시를 강조(예: "5/5") |
- **금지:** 아이템 사용/장착 등 콘솔 버전에 없는 기능 추가 금지(MVP는 조회만)
- **근거:** REQ-F-003

## SCR-005 · 퀘스트 패널
- **목적:** 현재 퀘스트 진행 상태 확인
- **진입:** SCR-002에서 퀘스트 보기 행동
- **가시 의무:**
  - 퀘스트 제목, 설명, 진행도(예: 0/1), 보상(경험치/골드), 상태 라벨
- **행동:**
  - 닫기 → SCR-002로 복귀
- **상태별 표현:**
  | 상태 | 표현 |
  |------|------|
  | 시작 전/진행 중/완료/실패/보상 수령 | QuestStatus 그대로 라벨 표시(STATE-003) |
- **금지:** 퀘스트 수락/거절 선택 등 새 기능 추가 금지(콘솔 버전은 자동 시작)
- **근거:** REQ-F-004

## SCR-006 · 게임 오버 화면
- **목적:** 패배 통보와 최종 상태 요약, 재시작 유도
- **진입:** SCR-003에서 패배 (FLOW-003)
- **가시 의무:**
  - "GAME OVER" + 패배 서술 텍스트
  - 최종 플레이어 상태(레벨/HP/공격력/방어력/경험치/골드)
  - "타이틀로 돌아가기" 버튼
- **행동:**
  - 타이틀로 돌아가기 → SCR-001 (네비게이션 스택 리셋)
- **금지:** 이 화면에서 바로 "다시하기"로 새 게임을 즉시 시작하지 않는다 — 타이틀에서 명시적으로 "새 게임"을 눌러야 함(세이브 덮어쓰기 오조작 방지, OQ-002와 연결)
- **근거:** REQ-F-005 · FLOW-003

## SCR-007 · 던전 클리어(승리) 화면
- **목적:** 승리 통보, 퀘스트 보상, 최종 상태 요약
- **진입:** SCR-003에서 보스(던전 수호자) 처치 (FLOW-003)
- **가시 의무:**
  - "던전 클리어!" 서술 텍스트
  - 퀘스트 보상 획득 내역(경험치/골드)
  - 최종 플레이어 상태
  - "타이틀로 돌아가기" 버튼
- **행동:**
  - 타이틀로 돌아가기 → SCR-001
- **금지:** SCR-006과 동일 — 즉시 재시작 금지
- **근거:** REQ-F-005 · FLOW-003

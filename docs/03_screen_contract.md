# 03. 화면 계약 (Screen Contract)

> 인터뷰 영역 5 정리 — 화면별 "무엇을 반드시 보이고, 무엇을 할 수 있는가" · 상태: draft

## SCR-001 · 타이틀 / 메인 메뉴
- **목적:** 새 게임 시작 또는 기존 진행 이어하기
- **가시 의무:** 게임 제목, "새 게임"/"이어하기" 버튼(세이브 없으면 이어하기 비활성). 세이브가 있는 상태에서 "새 게임"을 누르면 덮어쓰기 확인 모달("기존 진행 상황을 덮어쓰시겠습니까?" + "예, 새로 시작"/"아니오")을 먼저 표시한다(DEC-122)
- **행동:** 새 게임 → 세이브 없으면 바로 SCR-002 / 세이브 있으면 확인 모달 → "예" 시에만 SCR-002, "아니오" 시 SCR-001 그대로 유지(아무 것도 덮어쓰지 않음) / 이어하기 → SCR-003(저장된 위치, 직업 복원됨)
- **금지:** 이번 범위에 없는 기능(세계관 업로드, 멀티플레이 로비 등) 노출 금지
- **근거:** REQ-F-105 · FLOW-101·103 · OQ-102/DEC-122

## SCR-002 · 직업 선택
- **목적:** 2~3개 직업 중 하나를 확정해 시작 스탯을 결정
- **진입:** SCR-001 "새 게임"에서만 (이어하기는 이 화면을 건너뜀)
- **가시 의무:** 직업 카드(캐릭터 시트) 2~3장(이름, 초상화, 시작 HP/공격력/방어력, 시작 아이템 미리보기 — DEC-111), "확정" 버튼. **2026-09-08 추가(DEC-123, Unity 한정): 마나·공격속도도 함께 표시**(시작 무기 보너스가 반영된 최종값 — `ClassSelectPanelController`)
- **행동:** 카드 선택 → 스탯 미리보기 강조 표시 / 확정 → SCR-003(던전 입구)
- **상태별 표현:** 아무 것도 선택 안 함 → "확정" 버튼 비활성
- **금지:** 스킬트리·성장 분기 등 이번 범위에 없는 직업 상세 정보 표시 금지(01_requirements Won't) — DEC-123은 스킬트리가 아니라 "직업별 고정 마나 스킬 1개"이므로 이 금지 원칙과 충돌하지 않는다(06_open_questions.md DEC-123 참조)
- **근거:** REQ-F-101 · FLOW-101

## SCR-003 · 탐색 화면
- **목적:** 현재 위치를 확인하고 다음 행동을 선택
- **가시 의무:** 상단 상태 바(직업명, HP/최대HP, 공격력, 골드, **2026-09-08 추가: 마나/최대마나 — DEC-123**), **현재 지역을 암시하는 배경 씬 일러스트**(2026-09-04 추가 — 07_visual_style.md "탐색 화면 = 배경 씬"), 던전 보드 타일 맵(전체 5지역 경로 + 현재 위치), 지역 설명 텍스트, 지역별 선택지(카드형)
- **행동:** 선택지 클릭 → 이동/전투 진입/아이템 획득/상태 확인/저장하고 종료, 인벤토리·퀘스트 보기 → 오버레이. 보드 타일 맵에서 이동 가능한 다음 타일을 클릭해도 "던전에 들어간다" 등 해당 선택지 카드와 동일하게 동작(DEC-110) — 타일 클릭이 카드에 없는 새 이동 경로를 여는 것은 아님. **2026-09-08 추가(DEC-123)**: 인벤토리에 POTION 아이템이 있으면 "아이템 사용: {이름}" 선택지가 각각 추가로 표시되고(이름에 "마나"가 포함되면 마나를, 아니면 HP를 value만큼 회복 후 소모), 아직 이 지역에서 쓰지 않았다면 "휴식하기(마나 회복)" 선택지가 추가된다(지역당 1회, 최대 마나의 40% 회복) — 둘 다 기존 지역별 번호 선택지 체계와 별개의 항상-표시 버튼이라 기존 선택지 번호에는 영향 없음
- **상태별 표현:** 무기고 이미 루팅함 / 고블린 이미 처치함(콘솔 버전과 동일 조건) / 이 지역에서 이미 휴식함(휴식하기 버튼 숨김, DEC-123)
- **근거:** REQ-F-102·103 · FLOW-102·103

## SCR-004 · 전투 화면
- **목적:** 턴제 전투 진행 — 행동 선택과 결과 확인
- **가시 의무:** **플레이어와 적을 화면 좌우에 크게 마주 세운 대립 구도(Versus) 씬**(2026-09-04 추가 — 07_visual_style.md "전투 화면 = 대립 구도")과 각각의 HP바, 라운드 번호, 직전 턴 로그, 행동 선택지(카드형). 기존의 작은 초상화 나열 방식 대신 인물 비중을 크게 키운다. **2026-09-08 추가(DEC-123, Unity 한정)**: HP바 옆에 플레이어 마나/최대마나 표시. 행동 선택지는 기존 "공격한다"/"도망친다" 2개에서 **"일반 공격"/"{직업별 마나 스킬}"/"마나 회복(재료 소모)"/"도망친다"** 로 확장된다 — 마나 스킬은 마나가 비용 이상일 때만, 마나 회복은 재료("마나 결정")를 갖고 있을 때만 선택지 자체가 노출된다(비활성 표시 대신 조건 미충족 시 선택지를 숨기는 방식으로 구현 — `ExplorePanelController.RenderBattle`)
- **행동:** 일반 공격/마나 스킬 → 공격속도가 더 높은 쪽이 먼저 행동(동률이면 플레이어 우선, DEC-123) → 결과에 따라 다음 라운드 또는 승리/패배 전환 / 마나 회복 → 재료 소모 후 마나 회복, 이후 적이 반격 / 도망 → 55% 성공
- **상태별 표현:** 진행 중 / 승리 / 패배 / 도망 성공 / 도망 실패(콘솔 버전 BattleResult 그대로)
- **금지:** 전투 중 저장하고 종료 선택지 노출 금지
- **근거:** REQ-F-102·104 · FLOW-102 · DEC-123

## SCR-005 · 인벤토리 패널
- **목적:** 보유 아이템 확인
- **가시 의무:** 아이템별 이름·종류·효과값·설명, 현재/최대 용량
- **행동:** 닫기 → SCR-003 복귀
- **근거:** REQ-F-103

## SCR-006 · 퀘스트 패널
- **목적:** 현재 퀘스트 진행 상태 확인
- **가시 의무:** 퀘스트 제목·설명·진행도·보상·상태 라벨
- **근거:** REQ-F-103

## SCR-007 · 게임 오버 화면
- **목적:** 패배 통보와 최종 상태 요약
- **가시 의무:** 패배 서술, 최종 스탯(직업 포함), "타이틀로 돌아가기" 버튼
- **금지:** 즉시 재시작 금지 — 타이틀에서 명시적으로 "새 게임"을 눌러야 함(세이브 덮어쓰기 오조작 방지)
- **근거:** REQ-F-104 · FLOW-102

## SCR-008 · 승리 화면
- **목적:** 승리 통보, 퀘스트 보상, 최종 상태 요약
- **가시 의무:** 승리 서술, 퀘스트 보상 내역, 최종 스탯, "타이틀로 돌아가기" 버튼
- **금지:** SCR-007과 동일 — 즉시 재시작 금지
- **근거:** REQ-F-104 · FLOW-102

S-01전투 결과 (STATE-102 BattleResult)SCR-004
진행 중
라운드 로그 누적, HP바 실시간 갱신. 가짜 진행률·낙관적 승리 표시 금지 — 실제 HP가 0이 되기 전엔 승패를 선표시하지 않는다.
승리
"승리했습니다!" + 획득 경험치/골드를 즉시 표시 → 다음 지역 또는 SCR-008.
패배
"전투에서 쓰러졌습니다" → SCR-007. 재시도는 타이틀에서 "새 게임"으로만(즉시 재시작 금지, SCR-007 금지 항목).
도망 실패
"도망에 실패했습니다!" 즉시 표시 후 적 반격 진행 — 전투 화면 유지(SCR-004).

색 단독 구분 금지HP 위험·전투 결과 등은 색 + 아이콘/텍스트로 이중 부호화(색맹 고려)
파괴적 행동"새 게임"으로 기존 세이브를 덮어쓰는 흐름은 OQ-102 미결정 — 확정 시 outlined-error 스타일 + 확인 다이얼로그로 처리(기본 포커스는 "취소")

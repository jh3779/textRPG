## 주요 플로우 (FLOW-*)
### FLOW-101 · 새 게임 시작 (직업 선택 포함)
```
ENTRY(타이틀) → SCR-001 ─[새 게임]→ SCR-002(직업 선택) ─[확정]→ SCR-003(던전 입구)
```
- 진입점: SCR-001의 "새 게임"
- 분기: 기존 세이브 있음 → 덮어쓰기 확인(OQ-102) / 없음 → 바로 직업 선택으로
- 직업 미확정 상태로는 다음으로 진행 불가(직업 카드 하나를 명시적으로 선택해야 "확정" 버튼 활성화)

### FLOW-102 · 탐색 → 전투 → 결과
```
SCR-003 ─[적 있는 지역 진입]→ SCR-004
   SCR-004 ─[승리]→ SCR-003(다음 지역) 또는 SCR-008(보스 처치 시)
   SCR-004 ─[패배]→ SCR-007
   SCR-004 ─[도망 성공]→ SCR-003(이전 지역)
   SCR-004 ─[도망 실패]→ 적 반격 후 SCR-004 유지
```
- 콘솔 버전의 `BattleResult`(PLAYER_WIN/PLAYER_LOSE/PLAYER_FLEE/FLEE_FAILED)를 그대로 매핑(STATE-102)

### FLOW-103 · 저장하고 종료 / 이어하기
```
SCR-003(안전 지점) ─[저장하고 종료]→ 로컬 세이브 파일 기록 → SCR-001
SCR-001 ─[이어하기]→ 저장된 직업·위치·스탯 복원 → SCR-003(저장된 위치)
```
- 진입점: SCR-003의 각 지역 메뉴에 있는 "저장하고 종료" (전투 중에는 제공 안 함, 콘솔 버전과 동일)
- 이어하기는 직업 선택(SCR-002)을 건너뛴다 — 이미 저장된 직업으로 복원되므로

## 네비게이션 스택 전략
| 전환 | 방식 |
|------|------|
| 게임 오버 / 승리 → 타이틀 | 진행 화면 스택 전체 제거, SCR-001로 리셋 |
| 저장하고 종료 → 타이틀 | 동일하게 스택 리셋 |
| 인벤토리/퀘스트 패널 | SCR-003 위에 뜨는 오버레이 — 닫으면 이전 화면 상태 유지 |

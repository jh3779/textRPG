# 02. UI Flow — 사용자 경로 · 화면 목록

> 인터뷰 영역 5 정리 · 상태: draft

## 화면 목록 (SCR-*)
| ID | 화면 | 목적 | 주요 상태 |
|----|------|------|-----------|
| SCR-001 | 타이틀 / 메인 메뉴 | 새 게임 시작, 이어하기, (문서상 자리만) AI 서술 모드 안내 | localStorage 세이브 유무에 따른 "이어하기" 활성/비활성 |
| SCR-002 | 탐험 화면 | 현재 위치 이름·설명, 이동/행동 선택지, 상단 상태 바(HP/ATK/Gold) | 5개 지역별 텍스트·선택지, 무기고 이미 루팅함, 고블린 이미 처치함 |
| SCR-003 | 전투 화면 | 라운드 진행, 플레이어/적 HP, 공격·도망 선택 | 전투 진행 중 / 승리 / 패배 / 도망 성공 / 도망 실패 |
| SCR-004 | 인벤토리 패널 | 보유 아이템 목록 확인(모달 또는 사이드 패널) | empty(아이템 없음) / 목록 / 가득 참 |
| SCR-005 | 퀘스트 패널 | 현재 퀘스트 제목·설명·진행도·보상 확인 | 시작 전 / 진행 중 / 완료 / 보상 수령 |
| SCR-006 | 게임 오버 화면 | 패배 통보 + 최종 상태 요약 + 재시작 도입 | — |
| SCR-007 | 던전 클리어(승리) 화면 | 승리 통보 + 퀘스트 보상 + 최종 상태 요약 | — |

## 주요 플로우 (FLOW-*)
### FLOW-001 · 새 게임 시작
```
ENTRY(웹 접속) → SCR-001 ─[새 게임]→ (기존 세이브 있으면 확인 모달)─[계속]→ SCR-002(던전 입구)
```
- 진입점: 웹 페이지 최초 로드
- 분기: localStorage에 세이브 있음 → 덮어쓰기 확인(OQ-002) / 없음 → 바로 시작
- 예외/복구: 서버(게임 API) 연결 실패 시 SCR-001에서 에러 배너 + 재시도 버튼

### FLOW-002 · 이어하기(불러오기)
```
SCR-001 ─[이어하기]→ (localStorage 세이브 서버로 전송, 상태 복원)→ SCR-002(저장된 위치)
```
- 진입점: SCR-001의 "이어하기" 버튼 (세이브 없으면 비활성화 + 안내 문구)
- 분기: 세이브 데이터 파싱 실패 → 에러 안내 + "새 게임으로 시작" 유도
- 예외/복구: 세이브 포맷 버전 불일치(콘솔 버전의 `version=1`과 동일 검증) → 불러오기 실패 처리

### FLOW-003 · 탐험 → 전투 → 결과
```
SCR-002 ─[적 있는 지역 진입/도전]→ SCR-003
   SCR-003 ─[승리]→ SCR-002(다음 지역) 또는 SCR-007(보스 처치 시)
   SCR-003 ─[패배]→ SCR-006
   SCR-003 ─[도망 성공]→ SCR-002(이전 지역)
   SCR-003 ─[도망 실패]→ 적 반격 후 SCR-003 유지(전투 계속)
```
- 진입점: SCR-002에서 전투가 있는 지역(어두운 통로/보스의 방) 진입 선택
- 분기: 콘솔 버전의 `BattleResult`(PLAYER_WIN/PLAYER_LOSE/PLAYER_FLEE/FLEE_FAILED)를 그대로 매핑(STATE-002 참고)
- 예외/복구: 없음(턴제 동기 처리, 로딩 상태는 서버 응답 대기 스피너 정도)

### FLOW-004 · 저장하고 종료
```
SCR-002(안전 지점) ─[저장하고 종료]→ 세이브 상태를 localStorage에 기록 → SCR-001
```
- 진입점: SCR-002의 각 지역 메뉴에 있는 "저장하고 종료" 선택지(전투 중에는 제공 안 함 — 콘솔 버전과 동일)
- 분기: 저장 성공/실패 토스트 후 SCR-001로 복귀

## 네비게이션 스택 전략
| 전환 | 방식 |
|------|------|
| 게임 오버 / 던전 클리어 → 타이틀 | 진행 화면 스택 전체 제거, SCR-001로 리셋 |
| 저장하고 종료 → 타이틀 | 동일하게 스택 리셋 (전투 중간 상태로 되돌아가지 않음) |
| 인벤토리/퀘스트 패널 | SCR-002 위에 뜨는 오버레이 — 닫으면 이전 화면 상태 유지(스택에 새 항목 추가 안 함) |
